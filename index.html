    À propos de Cassi[net]

    Cassi[net] calcule des itinéraires et des isochrones sur le réseau routier de la carte de Cassini (XVIIIe siècle). Cliquez sur la carte pour choisir un départ, une arrivée, le centre d'une isochrone ou une zone à éviter.

    Données. Réseau Cassini et tâches urbaines : EHESS / LaDéHis [publication – données ouvertes – topologie]. Altimétrie : IGN Géoplateforme. Relief 3D : Mapzen / AWS Terrain Tiles.

    Technique. PostgreSQL 16 / PostGIS 3.4 / pgRouting 3.6, MapLibre GL JS. Documentation de l'API.

    Code par Éric Mermet (CNRS / Huma-Num / Projet Time Machine).
